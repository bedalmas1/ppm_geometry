\section{Experimental Setup}\label{sec:setup}

\paragraph{Event logs.}
We use five public logs (\cref{tab:datasets}) chosen for structural diversity
before any model was trained. They range from short, near-linear cases
(Helpdesk) to long, variable cases with frequent rework (Sepsis, BPIC17).
Cases are ordered by start time and split 64/16/20 into train, validation and
test, so every test case starts after every training case. One shared
pipeline produces the split, whose SHA-256 hash is checked by every model; the
vocabulary is built from training data only. For BPIC19 we drop events dated
outside $[2018\text{-}01, 2019\text{-}02)$, the cut-offs used for
SuTraN~\cite{wuyts2024sutran}. This removes 327 events (0.02\%) and no case.

\paragraph{Models and shared scope.}
\famA (\cref{tab:roster}) comes from a systematic search of 2021--2026 PPM
work. A model was admitted only if its public code ran and its pre-head layer
could be located in the source. All models are restricted to the activity
sequence and activity targets: time and remaining-time heads, resource
branches and extra attributes are removed, so every model sees identical
information. This affects LUPIN most, because its contribution is a rich
attribute-to-text encoding. Where paper and code disagree, we follow the code,
which produced the published numbers. Examples are RLHGNN's node max-pool
read-out and MLMME's ReLU before the cross-entropy. RLHGNN uses its fixed
``comprehensive'' graph instead of the RL-selected one, which its own ablation
places within about one GMean point. For MLMME we omit a \texttt{detach()}
that would silence the adversarial gradient under activity-only targets.
Hyperparameters follow each paper or repository. All models select their
checkpoint on validation data and use a single seed (42). LUPIN's budget was
reduced for compute (batch size 8$\to$32, 512$\to$48 tokens, 50$\to$15
epochs). The suffix window of A4--A7 is capped at the 99th percentile of
training lengths, which has no effect on Helpdesk. $\z_t$ is extracted for
every test prefix, and re-derived predictions reproduce each model's
recorded test metric exactly.

\paragraph{Reproducibility.}
Every artefact records the split hash, the resolved configuration, the seed,
the git commit, framework versions and the device. Embedding caches are
hashed against checkpoint, split and code. All tables are generated by
scripts. The code of LUPIN (CC~BY-NC-SA) and MLMME (GPL-3.0) is kept isolated.
RLHGNN's repository has no licence, so our version is a reimplementation.
